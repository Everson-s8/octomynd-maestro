# Maestro v0.4.2

## Novidades

- Introduz o Maestro Setup: um instalador Windows com identidade visual própria,
  etapas de instalação reais, progresso, verificação SHA-512 do pacote e logs
  recuperáveis.
- Mantém o instalador NSIS versionado como payload para atualizações automáticas
  e oferece o `Maestro-Setup.exe` como entrada de instalação para clientes.

## Validação

Validado em 2026-09-25, em Windows x64 com Node 24.19.0:

- `npm ci`: concluído, 0 vulnerabilidades.
- `npm run typecheck` e `npm run typecheck:ui`: passaram.
- `npm test -- --maxWorkers=2`: 91 arquivos e 878 testes passaram.
- `npm run release:win`: gerou o payload NSIS, o bootstrapper e metadados.
- `npm run verify:release`: confirmou os quatro artefatos e a versão 0.4.2.
- Testes do bootstrapper: 9 passaram.

A atualização de um Maestro instalado v0.4.1 para v0.4.2 ainda precisa ser
confirmada em uma instalação cliente real; build e publicação, sozinhos, não
comprovam o ciclo completo de descoberta, download e reinício automático.

SmartScreen. Baixe os arquivos apenas desta release e confira o SHA-256 do
