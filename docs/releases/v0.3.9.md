# Maestro v0.3.9

## Highlights

- Prevented unconnected or removed providers from being selected as active or fallback providers.
- Kept recoverable Goals running through provider failures, manual reroutes, and project-local test-environment repair while preserving the existing worktree and checkpoints.
- Added task-scoped workspace approval for agent commands and project-local dependency changes inside isolated worktrees; no global provider permissions are changed implicitly.
- Added visible desktop version and update progress, including a restart action when an update is ready.
- Routed ordinary Telegram messages through Maestro chat, with persistent general/project context and a path to continue in a project created from chat.
- Improved intake and recovery feedback so detailed user intent and useful execution evidence survive retries and provider changes.

## Distribution

This release is published from the `Octomynd/octomynd-maestro` repository with
the complete Windows update artifact set required by `electron-updater`.
