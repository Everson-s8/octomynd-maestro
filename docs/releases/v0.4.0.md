# Maestro v0.4.0

## Highlights

- Fixed `maestro.cmd status` in the packaged Windows app when resolving its
  production health-check helper.
- Improved spacing between connected provider cards and the action to connect
  another provider.
- Added a retry action and an official manual-install link when automatic
  update discovery or installation fails.
- Added regression coverage for update download progress and the ready-to-restart
  state.

## Client update validation

- Source version: v0.3.9.
- Target version: v0.4.0.
- Production GitHub Releases feed: pending validation.
- Download, restart, and user-data preservation: pending validation.
- Recovery and manual-install fallback: covered by UI and updater tests; client
  runtime verification pending.

## Distribution

`latest.yml` so existing installations can update through `electron-updater`.
