# Maestro v0.4.0

## Highlights

- Fixed `maestro.cmd status` in the packaged Windows app when resolving its
  production health-check helper.
- Improved spacing between connected provider cards and the action to connect
  another provider.
- Added a retry action and an official manual-install link when automatic
  update discovery or installation fails.
- Added regression coverage for update download progress and the ready-to-restart
  state.

## Client update validation

- Source version: v0.3.9.
- Target version: v0.4.0.
- Production GitHub Releases `latest.yml`: validated with HTTP 200; it declares
  `0.4.0` and references `Maestro-Setup-0.4.0-x64.exe`.
- Automatic background download from the running v0.3.9 client: verified on
  2026-09-23 at 05:48 BRT. The pending installer reports v0.4.0 and its SHA-256
  matches the published release checksum.
- Restart and user-data preservation: pending validation. The running app still
  reports v0.3.9 and is awaiting restart to apply the downloaded update.
- Recovery and manual-install fallback: covered by UI and updater tests; client
  runtime verification pending.

## Build validation

- Built on Windows from the v0.4.0 source tree on 2026-09-23 with Node 24.19.0
  and Electron 43.4.1.
- `npm run verify:release` confirmed the installer, `.blockmap`, and `latest.yml`
  declare and reference v0.4.0 consistently.
- The packaged `maestro.cmd status` exited successfully and reported the local
  dashboard API online.
- The existing v0.3.9 installer and `.blockmap` were preserved during the build;
  the installer SHA-256 still matches the v0.3.9 release record.

## Distribution

This release must include the Windows installer, its `.blockmap`, and
`latest.yml` so existing installations can update through `electron-updater`.
