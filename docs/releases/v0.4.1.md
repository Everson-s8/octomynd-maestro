# Maestro v0.4.1

## Highlights

- Grants autonomous task execution only inside the task's governed worktree,
  with explicit, persisted workspace consent.
- Adds deterministic validation for Python projects, including virtual
  environment-aware test discovery and Python compile checks.
- Covers desktop update-badge states with focused UI regression tests.
- Improves spacing between connected providers and the connect-provider action.

## Validation status

This is a release candidate prepared from `main` after PRs #202–#206. It is not
published yet. On 2026-09-23, under Node 24.19.0 and Electron 43.4.1:

- `npm run typecheck` and `npm run typecheck:ui` passed.
- `npm test -- --maxWorkers=2` passed: 88 files, 830 tests.
- `npm run build:backend`, `npm run build:ui`, and `npm run release:win` passed.
- `npm run verify:release` confirmed the installer, `.blockmap`, and `latest.yml`
  all declare and reference v0.4.1.
- The installer is unsigned (`Get-AuthenticodeSignature`: `NotSigned`). The
  build also reports the existing >500 kB UI chunk and Electron Builder's
  `asar`-disabled warning.

The included code changes have green CI on Windows and Ubuntu. The release
candidate itself is prepared locally; this document-only/version-bump PR still
needs its own CI before merge.
