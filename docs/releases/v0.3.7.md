# Maestro v0.3.7

## Highlights

- Added the interactive `maestro chat` terminal REPL over the same governed
  chat service used by the dashboard.
- Fixed first-turn terminal cancellation so Ctrl+C can stop a request before
  the REPL receives its thread identifier.
- Consolidated CLI environment/database helpers and marked CLI-originated
  commands with the `cli` channel.
- Added release verification for the installer, `latest.yml`, and blockmap
  required by `electron-updater`.

## Distribution

This release is published from the transferred `Octomynd/octomynd-maestro`
repository with the complete Windows update artifact set.
