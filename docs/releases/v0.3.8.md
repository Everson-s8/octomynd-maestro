# Maestro v0.3.8

## Highlights

- Made the dashboard chat resilient while conversation history is loading or
  recovering from a failed request; users can continue sending messages.
- Replaced the native task confirmation dialog with an in-app, scrollable
  confirmation flow for generated implementation briefs.
- Added explicit failure feedback and bounded timeouts for governed chat
  actions, preventing task creation from leaving the interface stuck.
- Persisted Full Access selection per conversation and kept it separate from
  Standard task creation permissions.
- Added protection against stale project/thread requests overwriting the
  active conversation state.

## Distribution

This release is published from the transferred `Octomynd/octomynd-maestro`
repository with the complete Windows update artifact set required by
`electron-updater`.
